# Repository-wide agent instructions

All agents working in this repository must follow the instructions in [docs/AGENTS.md](docs/AGENTS.md), including the mandatory **GitHub-plugin-only editing workflow** and the **pull request presentation standard**. Read that document before making repository edits or opening/updating a PR.

For every PR, default to a clear, polished GitHub Markdown layout like [Barrows historical accuracy audit PR #56](https://github.com/SoloScape/SoloScape-2006/pull/56): a descriptive title, purpose and status, a concise summary, useful tables, grouped and numbered findings or changes, direct source-code links, verification details, and outstanding work.

Do not add checkboxes to numbered findings or headings unless explicitly requested. Keep claims accurate, distinguish implemented work from unresolved findings, and preserve existing PR content when restyling it.
